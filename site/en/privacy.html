Privacy Policy (Zero Logs)

Cloak Manual is built on a foundational principle: the strongest data protection is collecting none at all. We do not collect, store, monetize, or share any information about site visitors with third parties.

1. Zero Logs Principle (Project-Side Zero Logging)

This project maintains no connection logs of its own and does not collect IP addresses, User-Agent headers, or browsing history (when hosted on static infrastructure such as GitHub Pages, network transport is handled by the hosting provider, while the site itself contains zero server-side or client-side telemetry).

2. Zero Cookies and Trackers

This site is 100% free of third-party analytics, marketing pixels, and tracking scripts (including Google Analytics, Yandex.Metrica, social media trackers, Hotjar, and similar services). The site never sets or reads cookie files.

3. Browser Local Storage (LocalStorage)

The site uses browser web storage strictly for local UI preferences — saving your selected color theme and interface language:

  • bp_theme — stores "dark" or "light".
  • bp_lang — stores "ru" or "en".

These settings never leave your device, are never transmitted over the network, and can be cleared at any time by deleting site data in your browser.

4. Browser-Level Isolation (Content Security Policy)

The site enforces a strict Content Security Policy (CSP) via HTTP headers and meta tags:

connect-src 'none'; frame-src 'none'; object-src 'none'; default-src 'none';

The connect-src 'none' directive instructs the browser to block all outbound network requests (XHR, Fetch, WebSocket), making telemetry exfiltration technically impossible.

5. Offline Mode (PWA & Service Worker)

The site operates as a Progressive Web Application. After the initial load, a local Service Worker caches pages on your device. You can disconnect from the internet or read the site inside an air-gapped virtual machine — it remains 100% functional offline without making network requests.

6. External Links

The manual links to third-party research, legislation, and web archives. Every external link includes rel="noopener noreferrer nofollow" alongside Referrer-Policy: no-referrer, preventing page URL leakage when opening external resources.
